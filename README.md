# AppNook

A responsive app directory backed by Cloudflare Pages Functions and D1.

- Public visitors can browse, search, and download apps.
- Admin-only dashboard at `/admin/`.
- D1 binding name: `DB`.
- Configure `ADMIN_USERNAME`, `ADMIN_PASSWORD` (Secret), and `SESSION_SECRET` (Secret) in Cloudflare Pages.
- See `SETUP_BN.md` for Bengali deployment instructions.
